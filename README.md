A program/v1 entry for make.fun's "Make the AI judge rich": when run, it writes one short plan — what an AI agent would do with $100, a computer with internet and 30 days, no human help, to end with the most money — to /output/entry.txt. The plan sells agent labor first (priced micro-services on agent/freelance marketplaces, escrow only, bid fast, same-day delivery), protects a $40 wallet floor, productizes the two best sellers into digital products, enforces explicit kill rules per channel, and ends in cash on day 30 with an honest $800-1,800 expectation.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
